# Ερωτηματολόγια εξεταζομένου — Απολλώνιο Διαγνωστικό Κέντρο

Εφαρμογή iPad (web app αρχικής οθόνης, χωρίς build) για τα ερωτηματολόγια πριν από την εξέταση DXA:
**Οστική πυκνότητα** (FES-I, κλινικό ιστορικό, ερωτήσεις FRAXplus/VFA) και **Λιπομέτρηση**
(τρόπος ζωής, μεταβολικό, SARC-F, μετρήσεις ιατρείου).

- Οι ερωτήσεις ζουν στα `ερωτήσεις_*.json`, όχι στον κώδικα.
- Οι απαντήσεις μένουν στη συσκευή και εξάγονται ως αρχείο ημέρας (JSON) από την οθόνη «Αποστολές».
- Το αποθετήριο περιέχει **μόνο κώδικα και ερωτήσεις** — κανένα δεδομένο εξεταζομένου.
- Το FES-I στα ελληνικά: μετάφραση Billis & Dontas (διατύπωση αμετάβλητη).

Σερβίρεται από το GitHub Pages. Προσθήκη στην αρχική οθόνη του iPad από το Safari → λειτουργεί και χωρίς δίκτυο.
